Project

Gobsplosion

A fast, chaotic monster-bashing experience built around fun visual impact, responsive combat, and exaggerated motion.

Blender Substance Painter Gameplay Art

Overview

Gobsplosion focused on creating a bold, vibrant identity for a high-energy action game. The visual language leans into punchy shapes, exaggerated materials, and strong silhouette readability so each creature and effect reads clearly in motion.

Production

From concept to final polish, this project involved building stylised props, environmental storytelling, and high-impact asset presentation. It was a strong exploration of colour, readability, and creating memorable moments in a compact game world.
