Project

Baba's Spectacular Square Up!

A playful, collaborative game project combining character-focused design, readable shapes, and a lively colour palette.

Environment Design Stylised Props Game Art

Overview

Baba's Spectacular Square Up! demanded a visual style that was both clear and expressive, balancing character charm with game readability. The project allowed exploration of fun geometry, upbeat materials, and packing personality into a stylised world.

Production

Working within a collaborative pipeline, this piece blended practical asset creation with creative exploration. The result was a coherent set of visuals designed to feel lively, approachable, and memorable from a gameplay perspective.
